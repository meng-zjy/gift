# 我们的小小世界

送给彼此喜欢的人的网页像素纪念游戏。当前版本为 **v0.4.0：回忆内容与本地管理**，可探索客厅、厨房与小卧室，并亲手添加日记、双方的话和多图相册。

## 启动

需要 Node.js 22.12+（或 20.19+）。在 VS Code 的 CMD 终端运行：

```cmd
cd /d D:\Programming\love
npm install
npm run dev
```

打开终端显示的 Local 地址，默认是 http://localhost:5173 。端口占用时 Vite 会选择下一个端口，请以实际输出为准。保持终端开启，Ctrl + C 停止服务；后续启动只需 `npm run dev`。不能双击 `index.html` 启动。

手机与电脑连接同一局域网时，打开终端输出的 Network 地址。若无法连接，请检查电脑防火墙是否允许 Node.js 的局域网访问。

## 操作

- WASD / 方向键：移动。
- 靠近家具或房门后按 E / 空格，或点击下方互动按钮。
- 淡菱形标记可以互动的物件；靠近任何一侧即可显示提示，无需站在下方或面朝物品。
- 手机：按住方向按钮移动，松开停止，靠近后点击互动按钮。
- Esc / 关闭按钮：离开阅读，保留当前段落。
- 切出页面自动暂停，返回后主动继续探索或阅读。
- 右上角「回忆册」：继续已发现的故事，或从头回看。

## 推荐体验路线

1. 初次进入会打开三段开场短笺，可以直接跳过。
2. 在客厅右上方书桌阅读日记，试试下一段、提前离开。
3. 和地毯左侧的小人对话；此角色固定在客厅。
4. 走到客厅右侧门旁，按 E 进入厨房。
5. 在左上方冰箱查看她的喜好；右侧餐桌放着草莓蛋糕小纸条。
6. 从厨房左侧门回到客厅，可重复往返。
7. 打开回忆册，继续刚才没读完的故事；从头回看不会改动原阅读进度。
8. 刷新页面后再打开回忆册，验证已发现内容和段落保留。
9. 客厅上方墙面可查看莫奈《睡莲》；从客厅下方门洞进入卧室，可查看梵高《卧室》。每幅画分别展示，支持原画与像素版切换。
10. 想模拟首次打开时，在回忆册底部选择“重新开始体验”，确认后会清除本浏览器的阅读进度。她使用独立浏览器首次访问时不会继承你的记录。

## 添加自己的回忆

1. 点击右上角「手账台」，或直接打开 `http://localhost:5173/#manage`（端口以实际启动地址为准）。
2. 新建日记、说过的话或出游相册，填写标题、日期、表达方、正文等信息。相册可添加多张 JPEG / PNG / WebP 照片，逐张填写说明、排序或移除。
3. 选择「草稿」或「发布」，点击「保存修改」。草稿只出现在手账台；发布后，日记在客厅书桌、话语在固定小人、相册在书架中查看。
4. 返回小屋后靠近对应物件。多篇内容会显示选择目录，选择后按段或按照片阅读。既有示例仍保留并标注演示。
5. 内容编辑后产生新的阅读修订，旧的已读状态不会让新内容自动变成已读。删除内容需确认；未保存离开会提示。

**保存与备份**：内容和图片存放在当前网站地址、当前浏览器的 IndexedDB 中，阅读进度单独存放。刷新、关闭浏览器或重置阅读体验不会删除内容；清理网站数据会删除。不同端口也属于不同网站来源。

手账台的「导出备份」生成包含图片的 `.memory-backup.json` 文件。更换浏览器或设备后导入，检查数量，再确认替换本机内容。导入不会带入阅读进度。备份和真实素材不进入 Git；`backups/` 与该备份扩展名已忽略。

当前管理入口没有登录，内容也不会随 Git 推送、构建或部署自动传到她的设备。服务器接入前，可用备份在目标浏览器恢复内容。这是本地管理里程碑，正式发布会接入服务器内容存储与管理身份验证。

## 当前范围与限制

- 已实现三间房往返、配置化入口、通用阅读与换房互动、碰撞和触屏操作。门洞嵌入墙边，仍需按互动键换房。
- 开场为简短文字配灯光淡入示意；人物与文案仍为临时演示。
- 食物喜好使用已提供的信息：草莓、芒果、小蛋糕与甜食。不喜欢的食物尚未提供，显示为空缺记录。
- 阅读分为未读完、已跳过、已读完；退出与从头回看分别处理。静态文字没有自动播放，不再提供多余的手动暂停按钮。
- 仅保存本浏览器的阅读记录，刷新会回客厅出生点，不保存角色位置。不支持跨设备同步。
- 已实现本地管理页、图片选择与压缩、多图相册、草稿发布、事务保存和完整内容备份；尚未接入服务器管理、视频、成就、音乐或生日蛋糕演出。
- 每本相册最多 20 张照片，单张原文件最多 10 MiB，自动按原比例缩小至最长边 1920；最多 1000 条内容，图片总量最多 60 MiB，备份最大 90 MiB。
- 家具与人物由程序绘制；真实画作与像素衍生版存放在本地 `public/art/`，来源见素材记录。运行时无需外部图片或字体请求。正式人物后续按提供的图片制作。

```cmd
npx playwright install chromium
npm test
npm run format:check
npm run build
npm run preview
```

测试覆盖碰撞、三房往返、画作、日记与人物对白、阅读恢复、内容草稿发布、修改修订、相册排序、备份跨浏览器恢复、写入失败、并发编辑冲突、窄屏操作与配置错误。真实手机、Safari 和线上部署仍需后续验证。

生产构建的 Phaser 引擎块会有体积提示；游戏模块已按需加载，后续根据线上首屏表现优化。

## 结构

```text
src/content/     房间与故事配置
src/game/        移动碰撞、配置校验、程序绘图与通用场景
src/ui/          阅读器、回忆册、阅读进度和操作界面
src/memories/    内容模型、仓库接口、本地存储与备份
tests/           碰撞、配置、内容存储与浏览器流程测试
docs/            计划、交付记录与扩展说明
archive/         保留的旧普通网页原型
```

当前使用单个 Vite 工程；后续增加服务端时再拆分。房间内容通过稳定 ID 引用，新增房间不需要复制场景代码；当前支持固定 480 × 320 地图及预设家具种类，Tiled 尚未接入。
