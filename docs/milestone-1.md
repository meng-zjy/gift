# 里程碑 1：两间房与可回看的故事

日期：2026-11-05

## 目标

在 Demo 0 基础上交付客厅与厨房往返，以及开场、日记、对白的暂停、跳过和回看。用户已授权自主推进并验证，到里程碑后再试玩调整。

## 本次实现

- 客厅右侧房门进入厨房，厨房左侧房门返回客厅。
- 同一个 Phaser 场景加载不同房间配置，复用输入、碰撞与互动逻辑，切换时清理旧显示对象。
- 每个房间独立指定名称、主题、提示、出生点、返回入口与家具。
- 互动使用区分明确的 `story` / `travel` 动作，校验房间和内容引用。
- 厨房包含冰箱、橱柜、餐桌、草莓蛋糕和植物；食物喜好仅使用用户已提供的信息。
- 初次开场短笺配灯光淡入示意，所有故事按段落阅读，无自动推进和强制等待。
- 阅读支持暂停、上一段、下一段、跳过整段剧情、提前离开。
- 回忆册仅展示已触发故事，区分未读完、已跳过、已读完；支持继续和从头回看。
- 本地阅读进度按版本保存，恢复时过滤未知内容、无效状态和越界段落。
- 回看独立于原阅读进度，不挪动角色或改写原阅读位置。
- 失焦或切后台暂停；阅读窗口内与探索画面都需要主动继续。
- 阅读时释放游戏对键盘的占用，允许弹窗按钮正常使用空格激活。
- 改进笔记本屏幕上的房间尺寸；修正临时角色腿部断开与顶着障碍仍走路的问题。

## 可体验路线

参见根目录 [README](../README.md)。建议完整体验一次：跳过开场 → 读日记一部分后离开 → 去厨房查看口味 → 返回客厅 → 在回忆册继续 → 刷新后回看。

## 存储边界

只保存本地阅读进度，键名为 `our-little-world:reading:v1`，不写入旧网页原型的数据。角色位置、当前房间、服务器账号与媒体文件不在本次存档范围内。

页面刷新后回到客厅；已经打开的开场不再强制弹出，可从回忆册继续。浏览器禁止写存储时仍可探索和阅读，并显示提示；刷新后可能无法恢复本次进度。
