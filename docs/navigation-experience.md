# v0.3.1：通路与交互改进

日期：2026-11-06

## 反馈与处理

1. **画作各有位置**：莫奈《睡莲》保留在客厅，梵高《卧室》放在新增小卧室。每个画框只查看自己的画，保留原画与像素切换、来源链接和回看。旧版 `paintings` 阅读 ID 保留给莫奈，旧进度按单页收敛；梵高有独立发现记录。
2. **可见通路可以走**：书架与冰箱原本距可行走边界不足一个角色碰撞箱宽，现调整布局留足上方通道；家具本体仍阻挡移动。橱柜同步留出通路。
3. **门嵌入墙边**：移除地板上孤立的门板，改为侧墙门洞、木质门框与门槛；客厅下方连接卧室。靠近后按 E / 空格或互动按钮换房，不会走过就自动传送。
4. **靠近四周都能交互**：按到物件边缘的距离提示，无需站在固定点或面朝它。物件常驻淡菱形，靠近后高亮。墙画从墙下地板接近；隔着别的实心家具不触发提示。入口位置避开冰箱提示，减少换房与物品争抢。

## 美术方向与范围

保留客厅的鼠尾草绿、木色与淡紫，厨房维持浅色墙砖。卧室使用雾蓝墙面、深蓝窗景、淡紫窗帘与浅木床架，与梵高画框形成安静的休息空间。固定绘制层级，继续采用平面移动。

本轮卧室是放置画作的最小可探索房间，没有虚构私人日记或新剧情。庭院建成后再安排星空题材，不把现有《卧室》误标为《星月夜》。

## 验证范围

- 碰撞：横穿客厅与厨房上方通路，同时验证书桌仍不可穿过。
- 互动：冰箱、书桌、蛋糕四边接近，阻挡物隔开时无误提示，远处不提示。
- 浏览器：从冰箱上方和右侧打开内容，三房往返，卧室独立画作实际加载，既有日记、回看、重置与触屏流程。
- 画面：查看客厅、厨房、卧室与画框截图；真实手机和 Safari 仍未实机验证。

- `npm test`：22 项全部通过（约 1.2 分钟）。
- `npm run build`：类型检查与生产构建通过；Phaser 引擎包仍有已知体积提示。
- `npm run format:check` 与 `git diff --check`：通过。
- 浏览器自动试玩采用新门洞的行走路线；调整按键时长后检查实际互动按钮，再执行换房，避免旧路线停在提示范围边缘。
