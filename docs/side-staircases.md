# v0.5.1：横向侧面楼梯

日期：2026-11-08

## 本轮调整

- 将纵向长条楼梯改为横向展开、有踏面、立面、扶手与阴影的侧面木阶。
- 客厅上楼梯靠右上角，下楼梯靠左下角；二楼与负一楼的返回楼梯靠左侧布置。
- 去掉楼梯上的文字和箭头。上楼使用抬升的木质侧面，下楼使用较暗的凹槽和向下延伸的踏步区分。
- 人物沿楼梯中心线同时改变屏幕 X/Y，按左右键即可连续升降，支持沿原路折返。保留平面碰撞、固定绘制图层与末端转场，没有增加高度轴或按 Y 排序。
- 转场仍会清理输入，落点避开楼梯触发区；减少动态效果模式保留实际行走，直接换房。

## 体验路线

- 客厅右上楼梯：走到左端低处，向右沿踏步上楼。
- 二楼左侧楼梯：从右端进入，向左下楼。
- 客厅左下楼梯：从右端进入，向左下到成就长廊。
- 成就长廊左侧楼梯：从右端低处进入，向左上回客厅。

## 扩展方式

`Staircase` 改为配置 `entry`、`exit` 两个点与目标房间，方向仍区分 `up/down`。踏步、扶手碰撞、末端触发区均从同一组坐标推导，避免画面和碰撞各自维护。配置校验检查方向与高差、横向跨度、目标入口和末端可行走性。

`movePlayer` 只在踏步通道里沿坡线移动；普通地板继续使用原有四方向移动。保留进入时的通道偏移，避免靠边进入突然吸附到中心。

本轮不修改回忆、成就或备份数据格式，既有内容和阅读记录继续沿用。
