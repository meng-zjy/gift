# Demo 0：走进客厅

日期：2026-11-05

## 本次可体验的流程

打开项目 → 移动临时角色 → 靠近书桌 → 打开演示日记 → 关闭 → 继续探索 → 与固定角色对话。

## 设计落点

- 客厅使用鼠尾草绿家具、淡紫地毯、蓝色窗户和小幅金色星空画。
- 480 × 320 的逻辑画布，根据容器缩放，关闭平滑采样。
- 角色上下左右移动，固定绘制图层，不使用 Y 坐标排序、透视缩放或高度轴。
- 房间配置与回忆正文独立；互动点通过稳定内容 ID 引用。
- React 负责阅读窗口和操作提示，Phaser 负责地图、人物和交互检测。
- 碰撞使用平面包围盒和移动子步，防止低帧率下穿过家具。
- 点击或短按互动键进入阅读后立即暂停游戏输入；关窗后恢复。
- 切出页面会释放方向输入并暂停，回来后主动继续。
- 没有自动播放或强制阅读；本版窗口可关闭、重开。尚未加入剧情序列。

## 启动与验收路线

参见根目录 [README](../README.md)。先检查移动、房间比例、角色大小、家具布局和阅读窗口是否符合预期，再考虑扩房和正式美术。

## 当前限制

- 两个角色和全部文字为占位示例，等待真实照片与文案。
- 只有客厅，没有其他房间入口；房间切换将在 Demo 1 完成。
- 暂不保存进度，刷新回到出生点。
- 无服务端、上传、成就、音乐和生日演出。
- 仅验证 Chromium 和窄屏模拟，真实手机、Safari 尚待验证。
- 原普通网页保存在 `archive/website-prototype/`，不参与新游戏构建。
