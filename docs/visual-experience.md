# v0.3.0：画面与交互展示改进

日期：2026-11-06

## 本轮处理的反馈

### 1. 浏览器无需缩放

删除首页大标题、下方介绍与页脚，改成全视口游戏布局。顶部只保留名字、房间和回忆册，房间画布与操作区按可用高度分配空间。小尺寸屏幕下保留触屏方向按钮。

验收尺寸：1366 × 768、1280 × 720、390 × 844、360 × 640。以默认浏览器缩放验证页面无横向或纵向溢出。阅读弹窗本身允许滚动长内容。

### 2. 家具细节

补充窗帘褶皱、窗外庭院、沙发缝线、靠垫、书脊、桌面纹理、小植物、冰箱贴、橱柜边线、水龙头、锅具、水果与蛋糕奶油层。

本轮提升占位素材的可辨认度，正式人物和完整美术仍待后续替换。角色和碰撞坐标没有改变。

### 3. 房间装修独立

- 客厅：竖纹墙纸、双庭院窗、布艺窗帘、木地板、莫奈画框。
- 厨房：浅色墙砖、单宽窗、时钟、厨具挂架、不同踢脚线与地砖。

房间主题通过独立的墙面绘制逻辑控制，不再只更换家具与地板。

### 4. 真实画作

从 Wikimedia Commons 获取莫奈《睡莲》和梵高《卧室》的公版复制图像。原比例缩放并制作像素版，文件保存在 `public/art/`，来源见 [素材记录](../public/art/CREDITS.md)。

走近客厅画框右下方，按互动键进入画廊。支持原画/像素版切换与两幅画浏览，提供来源链接。

### 5. 简化阅读与访客进度

静态文字没有自动播放，移除“暂停阅读”按钮。保留上一段、下一段、跳过与关闭；切出页面后保留内容，并在返回时主动继续。

回忆册只收录已发现内容，用于重读和继续，不预先列出全部内容。阅读记录保存在当前浏览器、当前网站来源的 localStorage，不打包在发布代码里。

- 她在自己的浏览器首次打开时不会继承开发者的阅读记录。
- 如果共用同一浏览器和同一网站地址，会看到该浏览器原有记录。
- 回忆册增加“重新开始体验”，二次确认后只清除本项目阅读记录并回到开场，不删除故事。
- localStorage 不会因重新构建或重新部署自动清空；需要测试全新访客时使用重置或独立浏览器环境。
- 当前没有账号与服务器同步；以后接入时需按访客/账号隔离，不把全局已读字段写入故事内容。

### 6. 不同物件对应不同展示

| 物件       | 展示                                 |
| ---------- | ------------------------------------ |
| 开场       | 深色短笺与亮灯小屋                   |
| 书桌日记   | 有书脊、页边线和横线的日记页         |
| 另一个小人 | 下方人物对话框与像素头像             |
| 冰箱       | 淡绿色口味卡片，草莓、芒果、蛋糕插画 |
| 餐桌蛋糕   | 甜品卡与奶油草莓蛋糕插画             |
| 墙面画框   | 深色画廊、清晰原画、像素切换和图注   |

展示通过故事类型选择，回看沿用相同样式。保留统一的关闭、分段与返回操作。
