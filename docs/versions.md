# 版本记录与 Git 约定

## v0.5.0：楼层、照片展板与成就长廊

- 平面楼梯支持实际行走、护栏碰撞、减速、折返与末端转场，连接一楼、二楼和负一楼。
- 二楼卧室承载日记，过道承载错落照片展板，翻图关闭返回展板。
- 负一楼成就长廊展示六项探索印记与手动发布的生活里程碑，可关联已发布回忆。
- 新备份格式 v2 包含生活里程碑，兼容旧 v1；重置体验只清除阅读和探索记录。
- 窗外统一白天，阳台和昼夜留待后续。

## v0.4.0：回忆内容与本地管理

- 独立手账台管理日记、双方说过的话与多图相册，支持草稿、发布、编辑、删除与搜索筛选。
- 发布内容接入书桌、小人和书架；支持分段、翻图、跳过、中断与回看。
- IndexedDB 保存结构化内容和图片，自动压缩、排序与清理失去引用的附件。
- 内容修订与阅读记录隔离，编辑后不会误用旧已读状态。
- 包含图片的版本化备份、导入校验和替换确认；多页并发编辑检查与事务失败恢复。
- 本轮仍为本地存储，没有登录、服务器同步或媒体外链。

- 客厅与厨房双向通行，冰箱口味记录与蛋糕故事。
- 开场、日记、对白可暂停、跳过、继续和回看。

## 后续约定

- 提交说明使用中文，每个提交围绕一个明确功能或修复。
- 可玩里程碑验证通过后创建带说明的版本标签，并同步到远程仓库。
- `main` 保留可运行版本，较大功能在独立分支开发。
- 不提交依赖目录、构建产物、测试输出、密钥、私人媒体或运行数据库。
- 已发布标签保持不动，修复使用新提交和新版本。

## 查看与回到历史版本

查看历史与标签：

```cmd
git log --oneline --decorate
git tag -n
```

先保存当前改动，再从历史版本创建独立分支体验：

```cmd
git switch -c review-v0.2.0 v0.2.0
npm ci
npm run dev
```

返回主分支后重新安装对应版本依赖：

```cmd
git switch main
npm ci
```

如果需要撤销已经发布的某次改动，使用 `git revert` 生成撤销提交，保留历史，避免强制覆盖远程分支。

体验 v0.4.0 等旧版本前先导出当前内容备份，并用不同端口或独立浏览器打开旧版本。旧代码不认识 v0.5.0 新增的生活里程碑；Git 回退只回退程序，不会同时回退浏览器里的内容数据库。
