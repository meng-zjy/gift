# v0.5.0：楼层、照片展板与成就长廊

日期：2026-11-07

## 本轮计划

- 一楼：客厅、厨房。移走日记与相册入口，保留迎接小人和画作。
- 二楼：楼梯过道与照片展板、卧室和日记书桌。
- 负一楼：成就长廊，区分个人探索印记与双方的生活里程碑。
- 上下楼：实际走入踏步区域，护栏用平面碰撞限制侧向穿入，踏步上减速，走到末端平台才淡出转场；允许中途折返。继续固定绘制图层，不采用按 Y 排序或高度物理。
- 照片展板：每本相册一张封面，胶带、轻微倾斜与错落排布；点开翻图，关闭返回原展板。小屏减少列数。
- 成就：探索印记根据到访楼层和阅读行为自动点亮，保存在访客进度里；第一次约会等真实生活事件由管理者记录日期、故事并发布，可关联已有回忆，进入内容备份。

阳台与昼夜系统继续作为后续里程碑，本版先保持各房间窗外同为白天。既有日记、相册和阅读 ID 沿用，只搬迁入口。

## 边界与验证

楼梯必须实际走完，互动键不会直接跳层。转场期间锁输入并显示去向，出生点避开触发平台，不会循环传送。验证上下楼、折返、护栏碰撞、切后台、触屏和重复往返。

生活里程碑不由游戏点击推断。预设第一次约会、第一次旅行、一起过生日，也支持自定义；未记录的保持待记录，不编造日期或经历。重复发布同一预设需阻止；关联回忆被删除或撤为草稿时，不泄露未发布正文，也不删除里程碑。

读取旧内容备份；新备份包含里程碑，格式版本升级为 2。重置体验清理阅读与探索进度，保留内容、图片和生活里程碑。

## 实现与扩展入口

- `src/content/upperHall.ts` 与 `achievementHall.ts` 定义新增空间；卧室继续沿用原房间 ID。
- `src/game/stairs.ts` 统一生成护栏碰撞、检测末端平台。通用场景负责减速、转场与输入清理，各房间只配置楼梯及目标入口。
- `src/achievements/definitions.ts` 定义六项探索印记和生活里程碑预设。探索记录保存在独立 localStorage 键，生活里程碑作为 IndexedDB 内容条目保存。
- `src/ui/MemoryCollection.tsx` 展示相册封面；阅读器叠在展板之上，关闭后保留原展板位置。成就故事也按同样方式返回长廊。
- 配置检查拒绝不存在的楼梯目标、越界平台，以及落在平台或碰撞区域内的出生点。新增房间与楼梯仍需实际走一遍验证路线。

探索徽章条件使用固定房间 ID，当前“走遍每个角落”明确对应五个房间；以后扩建可增加新徽章，避免改变已获得印记的含义。正式服务端、视频、阳台、昼夜与生日演出不在本次交付中。
