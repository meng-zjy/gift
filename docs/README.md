## 维护约定

- 已确认的需求、待确认信息与技术建议分别标明，避免将建议当成既定结论。
- 新功能先更新计划，再补充对应的详细设计与实现记录。
- 示例日期、对白和经历不代表真实信息；正式发布前必须替换或移除。
- 文档不存放账号密码、访问密钥或未经整理的私人内容。
