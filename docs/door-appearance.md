# 房门造型与墙体衔接

## v0.5.11：消除门贴在地板上的感觉

上一版虽然能辨认为门，但完整矩形门框、整块深色底板和门背后连续的灰色侧墙，仍然让它像一张贴在地板上的图片。

本轮改成侧墙在门口局部断开，露出上、下两处墙体断面和门洞深处；移除完整矩形外框，门槛穿过墙厚，半开门扇向室内展开并在地板上留出接触阴影。门扇背后可见屋内地板，深色仅用于真实门洞。左右侧门镜像共用此规则，门位、互动和存档没有改动。

验证：楼梯折返与上下楼测试通过，厨房阅读及连续三次往返测试通过。首轮厨房测试因固定时长按键未走到门口失败，追踪记录显示人物停在 `(100,199)`；改用实际位置行走到 `(60,210)` 后通过。已检查门洞局部放大截图。`npm run build`、`npm run format:check`、`git diff --check` 通过，构建仍有既有 Phaser 块体积提示；本次未重复运行全量内容管理测试。

## v0.5.10：房门造型与墙体衔接

### 试玩反馈与调整

原侧门仅有窄长绿色面板和多条横线，看起来像百叶窗。绘制范围延伸到房屋外轮廓，缺少清楚的门洞、门扇和墙体关系。

现在以室内墙面为边界，向屋内绘制木门套和门槛，外侧灰色房屋轮廓保留。门洞为深色，门扇采用半开轮廓，配上木质下镶板、鼠尾草绿上镶板、黄铜把手和合页。门洞表示相邻房间的入口，仍靠近后按 E 进入。

公共绘制位于 `src/game/doorArt.ts`，客厅、厨房、卧室和二楼过道的左右侧门按方向镜像。只调整外观，没有移动门的位置、改变碰撞、换房间规则或存档格式。

### 验证

- 厨房出入、喜好阅读和连续三次往返的浏览器测试通过，无页面异常，只有一个游戏画布。
- 已查看大厅房门局部放大图及厨房全图，确认门扇、把手和内侧门框清楚，外侧房屋边线保留。
- `npm run build`、`npm run format:check`、`git diff --check` 通过。构建仍有既有 Phaser 块体积提示；本轮仅修改绘制，未重复运行内容管理全量测试。
