# 庭院与出游回忆入口

## v0.6.3：庭院小花屋

长椅下方的浅绿矩形原用于区分休息区，试玩时看起来像独立地毯，本轮移除，只保留椅脚下的绿色阴影。

结合她喜欢花园绘画与甜食的偏好，将普通入口外立面改成小花屋：鼠尾草绿瓦与奶油色花边屋檐、左侧阁窗、圆顶木门、灰紫窗板、窗下花箱和攀缘藤蔓，门上点缀草莓徽记。图案都是程序绘制的装饰，不表示真实的私人纪念内容。小屋绘制拆到 `src/game/gardenHouseArt.ts`；外立面、碰撞和门槛互动继续使用既有配置。

验证：庭院地图相册打开、关闭和回屋的浏览器测试通过，已查看完整运行截图；构建、格式与差异检查见交付结果。本轮不改变移动与存档，不重复运行内容管理全量测试。

## v0.6.2：回屋入口与路旁陈设

根据反馈，木栅门难以表达“回到客厅”，长椅占用了道路，地图牌缺少支撑。本轮返回点改为小屋外立面：北侧绘制屋檐、窗户和门，保留稳定入口 ID，并将可互动区域投向门槛。小屋立面参与碰撞，人物从门口按 E 回到客厅。

新增沿 `x=226..254` 的支路，连接门槛与 `y=192..226` 的横向主路。长椅改放在 `(84,146)` 的路旁草地休息区。地图牌改为 `(300,126)`、高 60 的双立柱告示牌，纸质地图以图钉固定，继续打开已有出游相册。

验证：庭院进入、沿主路接近地图、打开并关闭相册、沿支路返回客厅的浏览器测试通过；主路完整双向行走和回屋支路往返测试通过；全房间入口校验通过。已查看运行截图。构建、格式及差异检查见本次交付。

## v0.6.1：露天庭院（2026-11-09）

根据试玩反馈，将绿色室内墙面、窗户和网格草地改为天空、云、树篱、连续草地与点缀石纹的土色小径。庭院边界改用植被色系，与室内房屋外框区分。

长椅使用独立 `bench` 类型，绘制三排木条靠背、座面和椅脚；`tree`、`flower` 在草地上直接生长，取消通用家具的棕色矩形底座。增加五处花朵与木栅门，使用柔和的绿色落地阴影。出游牌改用独立 `map-board`，不再显示厨房蛋糕桌；仍引用既有出游相册集合，实际照片和地点由用户后续填写。

回归测试已覆盖客厅进入庭院、走近地图牌打开相册、关闭后返回客厅；房间配置校验通过，已检查桌面运行截图。`npm run build`、`npm run format:check`、`git diff --check` 通过，构建仍有既有 Phaser 块体积提示。本轮未运行完整内容管理测试。

## v0.6.0 初版记录

## 目标

把计划中的庭院先做成可玩的最小空间，承载出去玩、散步和旅行记录。真实照片和用户提供的素材后续再从手账台绑定，不阻塞房间体验。

## 本轮内容

- 客厅下方新增“去庭院”门，庭院门可返回客厅。
- 庭院采用草地、木质横向步道、长椅和出游地图的程序绘制风格。
- 出游地图复用现有相册集合入口，后续可接入地图标记、日期和地点。
- 房间加入 `src/content/garden.ts`，沿用通用房间加载、移动、碰撞、互动和切换逻辑。

## 后续扩展

庭院下一轮可以加入长椅对白、地点标记、季节变化和通往阳台的路线；阳台再单独负责星空观察，避免与室内窗景重复。

## 验证

配置校验、移动通路和构建通过；新增浏览器测试验证客厅进入庭院、庭院门返回客厅。当前庭院使用演示美术和已有相册内容，未加入真实照片。
